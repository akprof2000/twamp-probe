# Одна проба, два съёмника, один ClickHouse и два конфигуратора

Примеры для Linux и TWamp v1.29.1. Замените демонстрационные IP на адреса своих машин. Верхний `Urls` привязывает службу к IP на её собственной машине. В интерфейсе оператора указывайте адрес, доступный с обеих машин конфигураторов и с обоих съёмников.

| Машина | Адрес примера | Куда поместить appsettings.json при штатной установке |
|---|---|---|
| Проба | http://192.0.2.10:8443 | /opt/twamp-probe-go/appsettings.json |
| Съёмник collector-a | http://192.0.2.21:9001 | /opt/twamp-collector/appsettings.json |
| Съёмник collector-b | http://192.0.2.22:9001 | /opt/twamp-collector/appsettings.json |
| ClickHouse | http://192.0.2.30:8123 | Этот HTTP-адрес указывается в ClickHouse.Url на двух съёмниках |
| Конфигуратор 1 | http://192.0.2.41:9000 | /opt/twamp-server/appsettings.json |
| Конфигуратор 2 | http://192.0.2.42:9000 | /opt/twamp-server/appsettings.json |

## Подстановка значений

- Во всех пяти файлах замените `REPLACE_WITH_SHARED_API_KEY` одним и тем же непустым ключом. В браузере каждого конфигуратора введите его в поле «Ключ API».
- В двух файлах съёмников замените адрес ClickHouse, пользователя `twamp_writer` и `REPLACE_WITH_CLICKHOUSE_PASSWORD` данными вашей установки. Укажите одну и ту же базу и таблицу. Примеры используют `twamp.results`. При обновлении сохраните действующие имена и путь к дисковому буферу. Пользователю ClickHouse требуются права на используемые операции CREATE, ALTER и INSERT.
- Для одного ClickHouse используется `ClickHouse.Url`, а список `ClickHouse.Urls` пуст. Съёмники получают адрес пробы и адрес коллеги при сохранении назначения. Каждый конфигуратор ведёт свою локальную TWamp.db.
- Если службы уже установлены, перенесите нужные значения в действующие файлы, сохранив свои параметры измерений, журналирования и хранения. Перезапустите службы после изменения JSON.

## Журнал и обмен

На каждом съёмнике в `appsettings.json` секция `NLog` определяет файл и ротацию, `Logging.LogLevel` — уровни категорий .NET. Штатный файл `/opt/twamp-collector/log/Collector.log` ротируется после 10 МиБ, хранится до пяти архивов. Журнал службы доступен командой `journalctl -u twamp-collector --since "30 min ago" --no-pager`. При запуске появится «Служба выгрузки в ClickHouse запущена». Начало сбора указывает владельца и адрес пробы. Для кратковременной детализации пачек задайте `Logging.LogLevel["SPI.Twamp.Collector"]="Debug"` и `NLog.rules[0].minLevel="Debug"` на нужном съёмнике.

На вкладке «Статус проб» блок «Обмен данными» показывает текущие показания с каждой машины. Для пробы видны число результатов до подтверждения, время и ID последней подтверждённой пачки, съёмник, размеры results.db и TaskInfo.json и свободное место. У съёмника видны строки в буфере, пачки до подтверждения, время чтения и успешной записи по каждой пробе, адрес ClickHouse и таблица. Время событий съёмника показано с последнего запуска. Последнее подтверждение пробы сохраняется при перезапуске. Опрос обновляется каждые 10 секунд на открытой вкладке. Данные отсутствующего узла помечаются как недоступные.

После подтверждения всей очереди Linux-проба автоматически уменьшает results.db, достигший порога `Probe:ResultCompactMinMiB` (по умолчанию 64 МиБ, 0 отключает автоматическое уменьшение). Проверка выполняется после последнего подтверждения, при запуске и раз в минуту. База меньше порога повторно использует место внутри файла. Для уменьшения пробе нужен небольшой временный файл на том же разделе. При росте числа ожидающих результатов сравните время подтверждения и последней записи в ClickHouse, наличие владельца и ошибки обоих съёмников. Не удаляйте results.db: там очередь измерений и назначение съёмников. При заполненном разделе сначала предоставьте пробе свободное место для записи.

## Первый запуск

1. Запустите пробу, оба съёмника и первый конфигуратор. Откройте в браузере http://192.0.2.41:9000. Во вкладке «Статус проб», в блоке «Съёмники», по очереди введите http://192.0.2.21:9001 и http://192.0.2.22:9001. Для каждого адреса нажмите «Зарегистрировать».
2. Введите http://192.0.2.10:8443 в поле адреса пробы, нажмите «Опросить пробу (CheckIn)», затем «Подтвердить». В строке пробы выберите основной `collector-a`, резерв 1 `collector-b`, резерв 2 оставьте пустым. Нажмите «Сохранить съёмники» и дождитесь подтверждения. Отправьте нужные задачи.
3. На втором компьютере откройте http://192.0.2.42:9000. В том же блоке «Съёмники» введите адрес любого настроенного съёмника и нажмите «Открыть конфигурацию со съёмника». Появятся действующие назначения и расписания. При переходе между рабочими местами повторяйте чтение перед правкой.
4. После применения настроек оба конфигуратора можно выключить. При отказе основного сбор подхватит резервный. После восстановления основного сбор автоматически вернётся к нему.

Для обмена нужны TCP-соединения от конфигураторов к съёмникам (9001) и пробе (8443), между съёмниками в обе стороны (9001), от съёмников к пробе (8443) и к ClickHouse (8123). Браузер оператора подключается к выбранному конфигуратору по TCP 9000. В канале управления и сбора проба только отвечает на входящие запросы.
