# SPI TWamp Probe (Rust) — эксперимент

Порт пробы на Rust: третья реализация того же контракта после C# и Go.
Совместима с сервером `SPI.Twamp.Server` без каких-либо изменений на его стороне —
те же эндпоинты, тот же JSON, та же механика ACK-доставки и cron-планирования,
тот же `appsettings.json`.

## Зачем

Сравнить три реализации одной пробы на одинаковой нагрузке: расход памяти и CPU,
размер поставки, поведение под тысячами параллельных замеров.

| Реализация | Размер бинарника | Рантайм на хосте |
|---|---|---|
| C# (self-contained) | ~44 МБ | не нужен |
| Go | ~6 МБ | не нужен |
| **Rust** | **~0.9 МБ** | не нужен |

## Сборка

```bash
cargo build --release
```

Готовый бинарник — `target/release/twamp-probe` (на Windows `twamp-probe.exe`).
Версия прошивается переменной окружения при сборке:

```bash
PROBE_VERSION=1.4.2-exp cargo build --release
```

Сборка под Linux с Windows (нужен установленный таргет):

```bash
rustup target add x86_64-unknown-linux-musl
cargo build --release --target x86_64-unknown-linux-musl
```

## Запуск

Рядом с бинарником положите `appsettings.json` (образец — в `deploy/`):

```bash
./twamp-probe
```

Файлы состояния создаются в рабочем каталоге: `TaskInfo.json` (реестр задач),
`results.json` (недоставленные результаты), `log/probe.log` (журнал с ротацией).

## Что реализовано

- **HTTP-контракт пробы**: `CheckIn`, `SetJobs`, `TaskIds`, `Tasks`, `TaskStatus`,
  `CheckData` (длинный опрос до 30 с), `ConfirmData`; пути и query-параметры
  сопоставляются регистронезависимо, как в ASP.NET.
- **Гарантированная доставка**: пачка не удаляется, пока сервер не подтвердит её
  (`ConfirmData`); недоставленное переживает перезапуск.
- **Реестр задач и cron**: инкрементальное слияние изменений, планирование по
  cron-выражению (5 и 6 полей), учёт даты окончания, сохранение на диск.
- **Диспетчер**: очередь + пул воркеров с ограничением `Probe:MaxParallel`
  (`0` — автоподбор «ядра × 16», потолок 10000).
- **Зонды**: `ping`, `twping`, `twampy` — внешними процессами; для `twampy` есть
  **встроенный отправитель** (`twampy:embedded: true`) без запуска python.
- **Сторож связи**: молчание сервера дольше `Probe:ServerTimeoutHours` — проба
  считает себя удалённой и чистит задачи с кэшем.
- **Журнал**: тот же формат, что у C#/Go-проб, ротация по размеру со сжатием.

## Тесты

```bash
cargo test
```

Покрыто: разбор контракта сервера (включая enum'ы числом и строкой), сериализация
результата, слияние и планирование задач, удаление по флагу `delete`, а также
встроенный twampy-отправитель — реальный UDP-обмен с рефлектором, случай полной
потери пакетов и формат единиц.
